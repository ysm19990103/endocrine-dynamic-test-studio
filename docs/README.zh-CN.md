# Endocrine Dynamic-Test Studio｜内分泌动态试验工作室

一个在浏览器本地运行的教学与作品集项目，用于探索内分泌时间曲线、记录检测方法假设，并显式展示数据质量问题。

[打开演示](https://ysm19990103.github.io/endocrine-dynamic-test-studio/) · [英文项目说明](../README.md) · [规则与来源](CLINICAL_RULES.md) · [安全与隐私](../SECURITY.md)

**教学原型，未经临床验证。仅使用合成案例。参考值比较不构成诊断、排除疾病或治疗建议。**

## 功能

- OGTT：GH、葡萄糖、胰岛素、总 GIP 和活性 GIP 独立时间曲线；峰值、最低值、梯形 AUC 和峰值较基线变化。
- 成人标准剂量 ACTH 结果复核；30 分钟特定方法阈值不使用 60 分钟结果替代。
- 已完成的过夜 DST 晨间结果比较；不自动诊断 MACS 或库欣综合征。
- IGF-1/ULN 比值，要求声明适用的实验室参考上限。
- 原始行顺序和空行保留；缺失、截尾、重复、时间不匹配与方法差异均有明确标记。
- 本地 CSV/JSON 导入，CSV/JSON/SVG 导出和打印报告；中英文界面标签。基于来源的比较解释保留英文，中文为非官方解释性翻译。

## 隐私

无 API 密钥、患者标识、私人研究数据、私有数据库、登录、追踪或案例持久化。运算在标签页内存中进行；刷新将返回合成示例。静态托管仍会收到正常页面/资源请求和网络元数据。下载文件和打印文件需由使用者管理。本项目不声明医疗法规合规性。

## 本地运行

Node.js 22 或以上，无 npm 依赖，无需安装依赖。

```sh
npm test
npm run build
npm run check
npm run dev
```

源 CSV 必须使用固定列 `planned_min,actual_min,analyte,value,unit,qualifier,assay`。不接受额外标识字段、自由文本或公式。完整会话设置请使用 JSON。详见 [数据格式](DATA_FORMAT.md)。

本项目展示临床信息学建模、透明规则、严格输入校验、数据溯源、安全边界及可复现测试能力，不代表已验证的医疗器械或已证实的临床效果。
